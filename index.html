MSc thesis · DTU

Outdoor Autonomous Path Planning ↗

An end-to-end perception → planning → navigation pipeline for outdoor mobile robots: semantic segmentation, BEV projection, local path planning and real-time control. Deployed on DTU’s Terrain Hopper robot.

  • Perception — U-Net++ segmentation & BEV
  • Planning — corridor / midline & pure pursuit
  • Deployment — Terrain Hopper + RealSense D455
  • Python
  • PyTorch
  • U-Net++
  • Intel RealSense

Warehouse Automation Design Review Assistant ↗

A local, evidence-grounded RAG workspace for reviewing warehouse-automation supplier design documents against requirements. Every candidate finding cites a document version, section and page.

  • Review packages — frozen, citable scope
  • Evidence chat & finding matrix with citations
